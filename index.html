B2B Core Pickup Request & ERP Lifecycle Integration
Architecture & Interactive Prototype

An end-to-end reverse logistics architecture designed to eliminate paper manifests and phone calls by digitizing lead-acid battery core collections within the enterprise portal.

  • ERP Financial Isolation: Submissions generate NetSuite Sales Orders using a dedicated non-inventory item (`pickup-only`) and custom Analysis Codes, completely insulating e-commerce P&L from branch-level core credit liabilities.
  • Field Fulfillment: Directly feeds driver pick-tickets into the mobile ION app for collection logging.
  • Credit Automation: Phase 2 automated NetSuite Credit Memo reconciliation directly mapped to portal order IDs.

B2B DoorDash Hot-Shot Dispatch & Multi-Location Mapping
Technical Specification

A localized 45-minute dispatch engine designed to capture emergency wholesale orders and counter scheduled weekly competitor routes.

Architecture Note: No custom UI prototype was required for this project. The front-end framework already exists on our B2C platform ("My Store" selector); this specification focuses on extending the address entity and repurposing those production UI assets for complex B2B multi-location hierarchies.
  • Address-Level Architecture: Maps servicing branch codes directly to the Magento Address entity to support single logins managing multiple child facilities.
  • Rate Limit Prevention: Evaluates local stock via Magento MSI to eliminate NetSuite API bottlenecks during browsing.
  • Logistics Tiering: Dynamic checkout weight enforcement (0–100 lbs vs 101–300 lbs) paired with courier no-touch safety rules.

Pre-Built POS & Shop Management Connectors (cXML / Webhooks)
Systems Integration Brief

Lightweight ERP/POS webhooks and cXML PunchOut connectors designed for dealer software (QuickBooks, Lightspeed, CDK Global) to maximize account retention and switching costs.

  • Single Source of Truth: Routes automated purchase orders through Magento so transactions remain visible in customer portals alongside manual orders and credit memos.
  • cXML PunchOut Support: Enables enterprise fleets (SAP Ariba, Coupa) to browse visual catalogs with real-time contract pricing while enforcing internal procurement approval flows.
  • Rapid Onboarding: Standardized REST endpoints reduce dealer integration lead times from 8–12 weeks (custom NetSuite EDI) down to 1–2 weeks.

NetSuite Automated Delivery Route & Schedule Architecture
Data Governance & ERP

Abstracting a frontend delivery-schedule feature request into a core ERP data governance solution to eliminate manual branch data entry and enforce downstream data completeness.

  • Discovery Root-Cause: A pre-development data audit revealed missing Delivery Day records caused by branch entry friction during account creation.
  • ERP Automation: Re-architected NetSuite to deterministically derive and populate Delivery Day automatically from the assigned Servicing Route.
  • Downstream Integrity: Unlocks clean data ingestion for Magento to display schedule windows and enforce dynamic 48-hour ordering cutoffs.
